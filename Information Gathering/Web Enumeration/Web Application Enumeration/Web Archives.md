
The [Wayback Machine](http://wayback.archive.org/) is a digital archive maintained by the Internet Archive that automatically captures, indexes, and stores historic snapshots of web pages across time, allowing security researchers to perform passive reconnaissance on past versions of a website.

How the Archive Works
Automated crawlers continuously visit web pages, downloading and archiving full site assets including HTML, CSS, JavaScript files, images, and external media linked to specific timestamped captures.
