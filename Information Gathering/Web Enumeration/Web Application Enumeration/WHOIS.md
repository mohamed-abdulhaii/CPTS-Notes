# Overview

WHOIS is a query and response protocol used to query databases that store registration information for internet resources, such as domain names, IP address blocks, and autonomous systems (ASNs).

A standard WHOIS record reveals structural administrative and technical details regarding a domain asset:

 - **Domain Name**: The registered domain asset.
 - **Registrar**: The organization managing the registration process (e.g., Amazon, GoDaddy, Namecheap).
 - **Registrant / Admin / Technical Contact**: Names, emails, phone numbers, and physical addresses of responsible personnel
 - **Creation and Expiration Dates**: Registration lifecycle timestamps useful for identifying domain renewal patterns or age.
 - **Name Servers (NS)**: DNS servers hosting the authority for translating the domain name into target IP addresses.

There are laws like GDPR and Domain Privacy, because of them much personal contact information is redacted.
