```
# Using curl
curl -k 'imaps://<target>' --user username:password
```

```

nc -nv <target> 110

```

# Overview

**Internet Message Access Protocol (IMAP)**, Which lets you read and organize emails directly on the server(access all folders). And synchronizes with all devices with the same email account.

**Post Office Protocol(POP3)**. lets you download emails from mail server (access only “inbox”)

**IMAP vs POP3:**
- POP3 downloads emails and deletes them from the server. IMAP keeps emails on the server, meaning an attacker who hacks an IMAP account sees all past emails and folders
-------------------------------------------------------------
**Ports : IMAP 143, 993 ——- POP3 110, 995**
Port 143 vs Port 993: Port 143 is standard IMAP and often sends passwords unencrypted. Port 993 is IMAP over SSL/TLS, which encrypts the connection. Same for Ports 110 vs 995 (POP3)

note : Plain Text Danger —>If port 143 does not use encryption, anyone listening on the local network can capture passwords in clear text.

--------------------------------------------------------------------------

there are misconfigurations in the server can be happened like

- **Anonymous Login (`auth_anonymous_username`):** Lets anyone log in to the mail server using a fake or blank password, just like anonymous FTP.
- **Password Logging (`auth_debug_passwords` & `auth_verbose_passwords`):** Forces the server to save actual user passwords into log files whenever someone tries to log in.
- **Authentication Debugging (`auth_debug` & `auth_verbose`):** Writes detailed internal information and failed login reasons to log files, helping an attacker map out the system.

the worst cases will allow us to read all the emails sent and received, which may even contain confidential or sensitive information.
