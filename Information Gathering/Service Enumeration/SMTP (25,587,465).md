# Cheat Sheet 
In SMTP service , the most important info you can get is : users or version of the service

| Command                                           | Description                                                                                                                                      |
| ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| telnet \<target> 25                               | try to grab the banner, it contain information                                                                                                   |
| nc -nv \<IP> 25                                   | also grab the banner                                                                                                                             |
| nmap -sC -sV -p25 -v target                       | use default scripts to enumerate the service and the default scripts contains smtp-commands scripts which lists all possible valid smtp commands |
| sudo nmap -p25 --script smtp-open-relay -v target | check if the mail server is a open relay by using 16 different methods                                                                           |
| smtp-user-enum -M VERY -U users.txt -t target     | enumerate valid users by using a wordlist, this enumerations can be unreliable depending on server configs                                       |
| nmap <IP> -p25 --script smtp-enum-users.nse       | enumerate users by using NSE                                                                                                                     |
| auxiliary/scanner/smtp/smtp_enum                  |  use this payload in metasploit to enumerate SMTP                                                                                                |

# Overview 

**Simple mail transfer (SMTP)** is used to sending and forwarding emails. Work with authentication (user:pass). And SMTP by default is plain text , but you can use STARTTLS command to start encrypted connection.

It can be used between client and server or server to server.
Port 465 is mostly for encrypted connection.

SMTP have three scenarios : 
1-open relay :  This is a misconfiguration , server allow anyone send emails through it 
2- lack of encryption : weak protection, leads to email interception
3- user enumeration : get a valid email address by analyzing server responses

Modern SMTP servers use ESMTP (ESMTP uses TLS, which is done after the `EHLO` command by sending `STARTTLS`). ESMTP supports AUTH command 
The **AUTH** command is an ESMTP command (SMTP service extension) that is used to authenticate the client to the server. the authentication methods 
1- plain auth (user and password are sent in clear text)
2- **AUTH LOGIN**
3- **AUTH CRAM-MD5**

SMTP offer more secure variants like SMTPS , using ssl/tls encryption for sensitive information during emails exchange

You need to understand three main terms for pentesting:
- **MUA (Mail User Agent):** This is the email app on your phone or computer, like Outlook.
- **MTA (Mail Transfer Agent):** This is the server that passes the email from one server to another.
- **Open Relay:** This is a misconfiguration where an MTA allows anyone on the internet to send emails through it.
